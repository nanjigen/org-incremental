This package is designed to bring [[https://supermemo.guru/wiki/Incremental_writing][incremental writing]], [[https://help.supermemo.org/wiki/Incremental_mail_processing][incremental mail processing]] and incremental [[http://www.literateprogramming.com/][literate programming]] capabilities to org-mode and Emacs.

It works with [[https://github.com/alphapapa/org-ql][org-ql]] in order to find and generate lists of included files.

The v0.3 development line requires Emacs 29.1 or newer.  This baseline permits
the package-owned browser to use built-in =vtable= directly instead of carrying
compatibility UI code for older Emacs releases.

Key functions we would need:
- A-factor
- Priority
- Postpone/Reschedule (Intra- and inter-day)
- Dismissing (of files and sub-headers)
- Mercy
- TODO keywords: ("to write", "to expand", "to rewrite", "to review", "finished")
- Statistical analysis to chart the progress through the writing material (~magit~ and ~calendar~)
- Outstanding headline sorting by priority to match circadian cycles (high for high alertness and low for end of day)

Features:

  + *Incremental literate programming* with org-mode and SM's algorithm!
  + *Incremental writing of email with tools like ~mu4e~!*
  + *Deadline awareness* (modify priority/a-factor/scheduled date based on distance to deadline)

Incremental writing is a concept co-developed by Piotr Wozniak and [[https://supermemopedia.com/wiki/How_I_use_creative_elaboration_with_the_help_of_incremental_reading][users of Supermemo]], employing its topic spacing feature to break writing projects into sub-chapters, which are then worked on in an 'incremental fashion', allowing the spacing algorithm to feed a writer these subsections with non-zero intervals between writing sessions - taking advantage of the spacing effect as a form of creative elaboration.

The spacing effect is a well-known psychological phenomenon that suggests that learning is more effective when information is presented over time, rather than all at once. This means that it is better to study or practice a subject in multiple sessions over time, rather than trying to learn everything at the same time (session).

Leveraging the spacing effect in the form of incremental writing allows a writer works on multiple writing projects 'simultaneously', rather than focusing on just one project for an extended period of time.

This approach can help writers overcome writer's block and produce more consistent work. By working on multiple writing projects simultaneously, a writer can take advantage of the spacing effect to improve their learning and memory. For example, if a writer spends a couple of hours working on one project, then switches to another project, then comes back to the first project later, they will be more likely to have worked through what they wrote subconsciously and be able to improve on it. This can help them produce better-quality work and avoid getting stuck on just one project.

The review spacings can thus be represented as a simple geometric sequence ($x_n=ar^{(n-1)}$) with =2= as the common ratio:

#+name: geometric-sequence-lua
#+begin_src lua :noweb yes :results silent
function geo_seq (a, r, n)
   local sequence = {}
   for i = 1, n do
   local x = a * r^(i-1)
   sequence[#sequence+1] = x
   end
   -- Ensure we are returning the table, not just the last value (x)
   return sequence
end

function print_seq (a, r, n)
  -- Capture the returned table into a variable called 'seq'
  local seq = geo_seq(a, r, n)
  for index, value in ipairs(seq) do
    print(value)
    -- tex.print(math.floor(value))
  end
end
#+end_src

Instead of re-implementing a geometric sequence directly, we'll copy SM's simple function and have our code act off of repetition data written to the ~:PROPERTIES:~ drawer or database depending on which backend the user chooses.

In the functional style the interval determining algorithm:
- We use =round= here because human work days are measured in real days, which means we have a full circadian cycle between reps.

#+begin_src elisp :noweb-ref spacing-algo :results silent
(defun org-incremental-determine-next-interval (old-interval a-factor)
  "Calcuate new interval for current headline.
Uses: (Interval=OldInterval*AFactor)"
  (let* ((safe-old (if (or (not old-interval) (= old-interval 0)) 1 old-interval))
         (next-interval (* safe-old a-factor)))
    (round next-interval)))

#+end_src

This can be compared to a geometric sequencer:
Note that we don't use ~cl-assert~ here when testing that r is greater than 0, as this macro can be stripped out based on the configuration of the ~cl-assertions~ variable.
#+begin_src elisp :noweb-ref spacing-algo :eval yes :results silent
(defun org-incremental-geometric (a r n)
  "Take the first term `A' and multiply by the common ratio `R'
To produce `N'th value in a sequence"
  ;; 1. Hard runtime type/boundary enforcement
  (unless (and (numberp r) (> r 0))
    (signal 'wrong-type-argument (list 'greater-than-zero-p r)))
  ;; 2. Sequence calculation core
  (if (> n 0)
    (* a (expt r (1- n)))))
#+end_src

Pure state transition function to calculate next state of current headline as a plist:
#+begin_src elisp :noweb-ref element-rescheduler :results silent
(defun org-incremental-calculate-next-state (old-interval a-factor prior-reps current-time)
  "Purely compute the next state updates based on current tracking data.
Returns a plist containing the computed mutations."
  (let* ((new-interval (org-incremental-determine-next-interval old-interval a-factor))
         (safe-old (if (or (not old-interval) (= old-interval 0)) 1 old-interval)) ;; sanitize
         (next-reps (1+ (or prior-reps 0))) ;; structural shield against unreviewed headlines
         (scheduled-time (time-add current-time (days-to-time new-interval))))
    (list :old-interval safe-old
          :new-interval new-interval
          :total-repeats next-reps
          :scheduled-time scheduled-time)))
#+end_src

Apply the base algorithm to existing ~:PROPERTIES:~ keys and then write the new interval, moving the previous interval into the "=OLD_INTERVAL=" key.
The element is rescheduled using ~org~'s internal =org-schedule= function which will be used later for building and sorting a que.

#+begin_src elisp :noweb-ref element-review-functions :results silent
(defun org-incremental-review-item () ;; TODO use arguments
 "Collect values from headline at point, compute updates, and apply mutations."
  (interactive)
  ;; Ensure the entry is initialized
  (unless (org-incremental-entry-p)
    (org-incremental--init-element))
  
(let* ((old-interval (org-incremental-element-current-interval))
         (a-factor (org-incremental-element-a-factor))
         (prior-reps (org-incremental-element-total-repeats))
         (now (current-time))
         
         ;; Pass data into our pure calculation engine
         (updates (org-incremental-calculate-next-state old-interval a-factor prior-reps now))
         
         ;; Extract values from the resulting plist
         (new-int (plist-get updates :new-interval))
         (total-reps (plist-get updates :total-repeats)))
  
    ;; Apply the mutations to each org element
    (org-entry-put (point) org-incremental-old-interval-property
                   (number-to-string (plist-get updates :old-interval)))
    (org-entry-put (point) org-incremental-new-interval-property
                   (number-to-string new-int))
    (org-entry-put (point) org-incremental-total-repeats-property
                   (number-to-string total-reps))
    (org-entry-put (point) org-incremental-last-reviewed-property
                   (org-incremental-time-to-inactive-org-timestamp now))
    
    ;; Update native org scheduling
    (org-schedule nil (plist-get updates :scheduled-time))
    
    (message "Scheduled out %d days ahead. (Repetition #%d)" new-int total-reps)))
#+end_src

(defun org-incremental-hypothetical-next-interval (old-interval factor steps)
"Calculate the hypothetical next interval after STEPS repetitions."
(let ((next-interval old-interval))
    (dotimes (_ steps)
      (setq next-interval (org-incremental-determine-next-interval next-interval factor)))
    next-interval))

(defun org-incremental-hypothetical-next-review-dates (&optional steps-to-predict)
  "Return a list of the next N hypothetical review intervals.
Extracts OLD-INTERVAL and A-FACTOR from the properties of the current headline.
Defaults to predicting the next 5 steps."
  (let* ((steps (or steps-to-predict 5))
         ;; Extract properties from the current headline using your properties
         (old-interval-str (org-entry-get (point) org-incremental-old-interval-property))
         (a-factor-str (org-entry-get (point) org-incremental-a-factor-property))
         ;; Parse strings to numbers, defaulting to sensible start values if missing
         (old-interval (if old-interval-str (string-to-number old-interval-str) 1))
         (a-factor (if a-factor-str (string-to-number a-factor-str) 2.0))
         (intervals nil))
    
    ;; Generate the list of hypothetical future intervals
    (dotimes (s steps)
      (push (org-incremental-hypothetical-next-interval old-interval a-factor (1+ s))
            intervals))
    
    (reverse intervals)))

(defun org-incremental--number-property (property aliases default)
  "Read numeric PROPERTY at point, falling back through ALIASES and DEFAULT.
The first present property wins.  Signal a clear error for non-numeric data."
  (let* ((properties (delete-dups (cons property (copy-sequence aliases))))
         (stored
          (cl-loop for name in properties
                   for value = (org-entry-get (point) name)
                   when value return (cons name value))))
    (if (null stored)
        default
      (unless (string-match-p
               "\\`[[:space:]]*[+-]?[0-9]+\\(?:\\.[0-9]+\\)?[[:space:]]*\\'"
               (cdr stored))
        (user-error "Invalid numeric Org property %s: %S"
                    (car stored) (cdr stored)))
      (string-to-number (cdr stored)))))

(defun org-incremental--excluded-path-p (path)
  "Return non-nil when expanded PATH matches an exclusion regexp.
Empty regexps in `org-incremental-excluded-path-regexps' are ignored."
  (unless (listp org-incremental-excluded-path-regexps)
    (user-error "org-incremental excluded path regexps must be a list"))
  (let ((expanded (expand-file-name path)))
    (cl-some
     (lambda (regexp)
       (unless (stringp regexp)
         (user-error "org-incremental exclusion regexp must be a string: %S"
                     regexp))
       (and (not (string= regexp ""))
            (condition-case error-data
                (or (string-match-p regexp expanded)
                    (and (file-directory-p expanded)
                         (string-match-p regexp
                                         (file-name-as-directory expanded))))
              (invalid-regexp
               (user-error "Invalid org-incremental exclusion regexp %S: %s"
                           regexp (error-message-string error-data))))))
     org-incremental-excluded-path-regexps)))

(defun org-incremental--normalize-sources (&optional sources)
  "Expand configured SOURCES into unique readable Org files or buffers.
Directory roots are searched recursively.  A scalar path, a list of paths,
explicit Org files, and live Org buffers are accepted.  Invalid values signal
a package-level `user-error' before `org-ql-select' is called.  Expanded paths
matching `org-incremental-excluded-path-regexps' are omitted."
  (let* ((configured (if (null sources) org-incremental-directories sources))
         (items (cond ((null configured) nil)
                      ((or (stringp configured) (bufferp configured))
                       (list configured))
                      ((listp configured) configured)
                      (t (user-error
                          "org-incremental directories must be a path or list"))))
         files-or-buffers)
    (dolist (item items)
      (cond
       ((bufferp item)
        (unless (buffer-live-p item)
          (user-error "org-incremental source buffer is not live"))
        (with-current-buffer item
          (unless (derived-mode-p 'org-mode)
            (user-error "org-incremental source is not an Org buffer: %s"
                        (buffer-name item))))
        (unless (and (buffer-file-name item)
                     (org-incremental--excluded-path-p
                      (buffer-file-name item)))
          (push item files-or-buffers)))
       ((stringp item)
        (let ((path (expand-file-name item)))
          (cond
           ((file-directory-p path)
            (unless (file-readable-p path)
              (user-error "org-incremental directory is not readable: %s" path))
            (unless (org-incremental--excluded-path-p path)
              (dolist (file
                       (directory-files-recursively
                        path "\\.org\\'" nil
                        (lambda (directory)
                          (not (org-incremental--excluded-path-p directory)))))
                (when (and (file-readable-p file)
                           (not (org-incremental--excluded-path-p file)))
                  (push file files-or-buffers)))))
           ((and (file-regular-p path)
                 (file-readable-p path)
                 (string-match-p "\\.org\\'" path))
            (unless (org-incremental--excluded-path-p path)
              (push path files-or-buffers)))
           ((file-exists-p path)
            (user-error "org-incremental source is not a readable Org file: %s"
                        path))
           (t
            (user-error "org-incremental source does not exist: %s" path)))))
       (t
        (user-error "org-incremental source must be a directory, Org file, or buffer"))))
    (let ((seen (make-hash-table :test #'equal))
          unique)
      (dolist (source (nreverse files-or-buffers))
        (let ((key (if (bufferp source) source (file-truename source))))
          (unless (gethash key seen)
            (puthash key t seen)
            (push source unique))))
      (nreverse unique))))

(defun org-incremental--element-from-org (marker &optional parsed-element)
  "Build a durable domain element from the Org heading at MARKER.
PARSED-ELEMENT may provide already-parsed headline metadata.  No ID is created
and file-backed results retain no dependency on the source buffer."
  (unless (and (markerp marker) (marker-buffer marker)
               (marker-position marker))
    (error "Org heading has no live source marker"))
  (let* ((source-buffer (marker-buffer marker))
         (file (buffer-file-name source-buffer)))
    (with-current-buffer source-buffer
      (save-excursion
        (save-restriction
          (widen)
          (goto-char marker)
          (org-back-to-heading t)
          (org-incremental--make-element
           :id (or (and parsed-element
                        (org-element-property :ID parsed-element))
                   (org-entry-get (point) "ID"))
           :file (and file (expand-file-name file))
           :position (point)
           :buffer (unless file source-buffer)
           :title (or (and parsed-element
                           (org-element-property :raw-value parsed-element))
                      (org-get-heading t t t t))
           :todo (org-get-todo-state)
           :tags (org-get-tags nil 'local)
           :priority (or (and parsed-element
                              (org-element-property :priority parsed-element))
                         (and-let* ((priority
                                     (org-entry-get (point) "PRIORITY")))
                           (string-to-char priority)))
           :scheduled (org-entry-get (point) "SCHEDULED")
           :last-reviewed
           (org-entry-get (point) org-incremental-last-reviewed-property)
           :total-repeats (org-incremental-element-total-repeats)
           :old-interval (org-incremental-element-old-interval)
           :new-interval (org-incremental-element-current-interval)
           :a-factor (org-incremental-element-a-factor)))))))

(defun org-incremental--element-from-org-ql-result (org-ql-element)
  "Convert ORG-QL-ELEMENT into a durable package-owned domain element.
This is the boundary where org-ql/org-element representation is consumed.
The legacy display snapshot is retained only for the old Outstanding view."
  (let* ((marker (org-element-property :org-marker org-ql-element))
         (element (org-incremental--element-from-org marker org-ql-element))
         (display-string
          (copy-sequence (org-ql-view--format-element org-ql-element))))
    (remove-list-of-text-properties
     0 (length display-string)
     '(org-marker org-hd-marker standard-properties)
     display-string)
    (setf (org-incremental--element-display-string element) display-string)
    element))

(defun org-incremental--kill-scan-buffers (buffers)
  "Kill temporary scan BUFFERS without running user cleanup hooks."
  (dolist (buffer buffers)
    (when (buffer-live-p buffer)
      (with-current-buffer buffer
        (set-buffer-modified-p nil)
        (let ((kill-buffer-hook nil)
              (kill-buffer-query-functions nil))
          (kill-buffer buffer))))))

(defun org-incremental--make-scan-buffer (file)
  "Return a temporary Org buffer containing FILE without visiting it normally.
Local variables, directory-local variables, local eval forms, and user-facing
major-mode hooks are suppressed."
  ;; org-ql deliberately ignores buffers whose names begin with a space.
  (let ((buffer (generate-new-buffer "*org-incremental-scan*"))
        success)
    (unwind-protect
        (with-current-buffer buffer
          (setq-local buffer-file-name (expand-file-name file))
          (setq-local buffer-file-truename (file-truename file))
          (setq-local default-directory (file-name-directory buffer-file-name))
          (setq-local buffer-offer-save nil)
          (setq-local create-lockfiles nil)
          (setq-local make-backup-files nil)
          (setq-local auto-save-default nil)
          (setq-local change-major-mode-hook nil)
          (buffer-disable-undo)
          (insert-file-contents buffer-file-name)
          (let ((enable-local-variables nil)
                (enable-dir-local-variables nil)
                (enable-local-eval nil)
                (text-mode-hook nil)
                (outline-mode-hook nil)
                (org-mode-hook nil)
                (change-major-mode-after-body-hook nil)
                (after-change-major-mode-hook nil)
                (before-hack-local-variables-hook nil))
            (org-mode))
          (setq buffer-read-only t)
          (set-buffer-modified-p nil)
          (setq success t)
          buffer)
      (unless success
        (org-incremental--kill-scan-buffers (list buffer))))))

(defun org-incremental--scan-buffer-has-headings-p (buffer)
  "Return non-nil when Org scan BUFFER contains at least one heading."
  (with-current-buffer buffer
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (re-search-forward org-outline-regexp-bol nil t)))))

(defun org-incremental--scan-sources (sources)
  "Return scan buffers and temporary buffers prepared from SOURCES.
Already-open file buffers and explicit live buffer sources are reused.  Closed
files are read into temporary buffers without normal file-visiting behavior."
  (let (scan-sources temporary-buffers success)
    (unwind-protect
        (progn
          (dolist (source sources)
            (cond
             ((bufferp source)
              (when (org-incremental--scan-buffer-has-headings-p source)
                (push source scan-sources)))
             ((stringp source)
              (let ((existing (find-buffer-visiting source)))
                (if existing
                    (when (org-incremental--scan-buffer-has-headings-p existing)
                      (push existing scan-sources))
                  (let ((buffer (org-incremental--make-scan-buffer source)))
                    (push buffer temporary-buffers)
                    (when (org-incremental--scan-buffer-has-headings-p buffer)
                      (push buffer scan-sources))))))))
          (setq success t)
          (list :sources (nreverse scan-sources)
                :temporary-buffers (nreverse temporary-buffers)))
      (unless success
        (org-incremental--kill-scan-buffers temporary-buffers)))))

(defun org-incremental-selection (sources query sort)
  "Select durable queue entries from normalized SOURCES.
Closed files are scanned through temporary Org buffers, so `org-ql-select'
never receives their paths.  Existing user-open buffers are preserved."
  (let* ((scan (org-incremental--scan-sources sources))
         (scan-sources (plist-get scan :sources))
         (temporary-buffers (plist-get scan :temporary-buffers)))
    (unwind-protect
        (when scan-sources
          (mapcar #'org-incremental--element-from-org-ql-result
                  (org-ql-select scan-sources query
                    :action 'element-with-markers
                    :sort sort)))
      (org-incremental--kill-scan-buffers temporary-buffers))))

The outstanding que shows scheduled items based on the current day, which we determine via [[https://supermemopedia.com/wiki/Midnight_shift][midnight shift]].

As mentioned in the /Topic spacing algorithm/ section, the spacing effect relies on sleep cycles between days to consolidated memory and for the formalization of new ideas. As such, we need a time against which to 'tick over' into the new day so that we can be sure that the algorithm is making the right calculations, and not using stale data.

We run this test as /midnight+midnight shift = a new learning day/.

At first, simply setting the shift time as midnight seems logical. However, in an increasingly 'on' world, we might find ourselves working past midnight. Thus it is likely best to set this somewhere in the middle of your usual sleep, i.e. while your brain is consolidating.

(defun org-incremental--fallback-heading-position (element buffer)
  "Resolve ID-less domain ELEMENT to a heading position in BUFFER.
Use the stored title to tolerate position shifts caused by earlier reviews,
choosing the matching heading nearest the original fallback position."
  (let ((fallback (or (org-incremental--element-position element) 1))
        (title (org-incremental--element-title element)))
    (with-current-buffer buffer
      (save-excursion
        (save-restriction
          (widen)
          (if title
              (let (matches)
                (goto-char (point-min))
                (while (re-search-forward org-heading-regexp nil t)
                  (goto-char (match-beginning 0))
                  (when (equal (org-get-heading t t t t) title)
                    (push (point) matches))
                  (forward-line 1))
                (unless matches
                  (user-error "Org incremental heading no longer exists: %s"
                              title))
                (car (sort matches
                           (lambda (left right)
                             (< (abs (- left fallback))
                                (abs (- right fallback)))))))
            (goto-char (min (max (point-min) fallback) (point-max)))
            (unless (org-at-heading-p)
              (org-back-to-heading t))
            (point)))))))

(defun org-incremental--element-marker (element)
  "Resolve durable domain ELEMENT to a live Org marker.
Prefer an existing Org ID within the recorded file, then use its fallback
position.  A non-file buffer source must still be live."
  (unless (org-incremental-element-p element)
    (error "Invalid org-incremental element: %S" element))
  (let* ((file (org-incremental--element-file element))
         (id (org-incremental--element-id element))
         (source-buffer (org-incremental--element-buffer element))
         (id-marker (and id file (org-id-find-id-in-file id file t))))
    (or id-marker
        (let ((buffer
               (cond
                (file
                 (unless (file-readable-p file)
                   (user-error "Org incremental source is not readable: %s" file))
                 (find-file-noselect file))
                ((buffer-live-p source-buffer) source-buffer)
                (t (user-error "Org incremental queue source is unavailable")))))
          (with-current-buffer buffer
            (save-restriction
              (widen)
              (goto-char (org-incremental--fallback-heading-position
                          element buffer))
              (point-marker)))))))

(defun elfeed--shuffle (seq)
  "Destructively shuffle SEQ."
  (let ((n (length seq)))
    (prog1 seq                  ; don't use dotimes result (bug#16206)
      (dotimes (i n)
        (cl-rotatef (elt seq i) (elt seq (+ i (random (- n i)))))))))

* v0.3 element browser

The package-owned browser consumes =org-incremental-element= records through
the model/query API.  It does not parse org-ql results, inspect org-element
plists, or depend on live source markers.  Org files remain canonical and are
opened normally only when the user visits or reviews a selected row.

#+begin_src elisp :noweb-ref browser :results silent
(defcustom org-incremental-list-buffer "*org-incremental: Elements*"
  "Buffer name used by the package-owned element browser."
  :type 'string
  :group 'org-incremental)

(defvar-local org-incremental-list--elements nil
  "Domain elements displayed in the current browser buffer.")

(defvar-local org-incremental-list--table nil
  "Vtable displayed in the current browser buffer.")

(defun org-incremental--display-date (timestamp)
  "Return date-only display text for Org TIMESTAMP."
  (if (and timestamp
           (string-match "[<[]\\([0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]\\)"
                         timestamp))
      (match-string 1 timestamp)
    "—"))

(defun org-incremental--display-priority (priority)
  "Return compact display text for PRIORITY."
  (cond ((null priority) "—")
        ((and (integerp priority) (<= 0 priority 9))
         (number-to-string priority))
        ((characterp priority) (char-to-string priority))
        (t (format "%s" priority))))

(defun org-incremental--reviewed-today-p (element)
  "Return non-nil when ELEMENT was last reviewed today."
  (equal (org-incremental--display-date
          (org-incremental--element-last-reviewed element))
         (format-time-string "%Y-%m-%d")))

(defun org-incremental--scheduled-today-p (element)
  "Return non-nil when ELEMENT is scheduled today."
  (equal (org-incremental--display-date
          (org-incremental--element-scheduled element))
         (format-time-string "%Y-%m-%d")))

(defun org-incremental-list--header-line ()
  "Return declarative status text for the current browser."

(defun org-incremental-list--render ()
  "Render `org-incremental-list--elements' in the current browser."
  (let ((inhibit-read-only t))
    (erase-buffer)
    (magit-insert-section (org-incremental-browser)
      (magit-insert-heading "Org Incremental")
      (insert "\n")
      (magit-insert-section (overview)
        (magit-insert-heading "Overview")
        (insert (format "  Outstanding: %d\n"
                        (length org-incremental-list--elements)))

                        (cl-count-if #'org-incremental--reviewed-today-p
                                     org-incremental-list--elements))))

        (magit-insert-heading "Outstanding")
        (setq org-incremental-list--table
              (make-vtable

               :objects org-incremental-list--elements
               :use-header-line nil
               :actions (list "RET" #'org-incremental-list-visit
                              "r" #'org-incremental-list-review)
               :separator-width 2))))
    (setq-local header-line-format (org-incremental-list--header-line))

  (interactive)

    (user-error "Not in an org-incremental browser"))
  (setq org-incremental-list--elements
        (org-incremental-outstanding-elements))
  (org-incremental-list--render))

(defun org-incremental-list ()
  "Open or refresh the package-owned incremental element browser."
  (interactive)
  (let ((buffer (get-buffer-create org-incremental-list-buffer)))
    (with-current-buffer buffer
      (unless (derived-mode-p 'org-incremental-list-mode)
        (org-incremental-list-mode))
      (org-incremental-list-refresh))
    (pop-to-buffer buffer)))

(defun org-incremental-agenda ()
  "Open a genuine Org Agenda containing outstanding incremental elements."
  (interactive)

                   org-incremental-directories))
         (org-agenda-files (cl-remove-if #'bufferp sources))
         (org-agenda-custom-commands
          `(("i" "Incremental outstanding"
             ((org-ql-block
               ,(org-incremental--default-query)
               ((org-ql-block-header "Incremental outstanding"))))))))

(transient-define-prefix org-incremental-dispatch ()
  "Command surface for sessions, elements, and views."
  [["Session"
    ("s" "Start" org-incremental)
    ("n" "Review and next" org-incremental-goto-next)
    ("p" "Previous" org-incremental-goto-previous)
